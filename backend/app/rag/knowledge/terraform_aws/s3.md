# AWS S3 Bucket Terraform Resource Specification

## Overview
The `aws_s3_bucket` resource provides an Amazon Simple Storage Service (S3) bucket.
In Terraform AWS Provider v4 and v5, S3 bucket configuration is modularized into sub-resources:
- `aws_s3_bucket`: Core bucket creation.
- `aws_s3_bucket_server_side_encryption_configuration`: Default encryption (AES256, aws:kms).
- `aws_s3_bucket_versioning`: Object versioning control.
- `aws_s3_bucket_public_access_block`: Public access prevention (CIS compliance).

## Resource: aws_s3_bucket

### Required Arguments
- `bucket` (Optional/Computed string): The name of the bucket. If omitted, Terraform will assign a random, unique name. Must be lowercase, numbers, hyphens, between 3 and 63 characters.

### Optional Arguments
- `force_destroy` (Optional bool, default `false`): A boolean that indicates all objects (including any locked objects) should be deleted from the bucket so that the bucket can be destroyed without error.
- `tags` (Optional map of string): A map of tags to assign to the bucket resource. Common keys: `Environment`, `Owner`, `Project`.

### HCL Example: Secure S3 Bucket
```hcl
resource "aws_s3_bucket" "storage" {
  bucket        = "vellum-secure-artifacts-bucket"
  force_destroy = true

  tags = {
    Environment = "production"
    ManagedBy   = "vellum"
  }
}

resource "aws_s3_bucket_versioning" "storage_versioning" {
  bucket = aws_s3_bucket.storage.id
  versioning_configuration {
    status = "Enabled"
  }
}

resource "aws_s3_bucket_server_side_encryption_configuration" "storage_encryption" {
  bucket = aws_s3_bucket.storage.id

  rule {
    apply_server_side_encryption_by_default {
      sse_algorithm = "AES256"
    }
  }
}

resource "aws_s3_bucket_public_access_block" "storage_pab" {
  bucket = aws_s3_bucket.storage.id

  block_public_acls       = true
  block_public_policy     = true
  ignore_public_acls      = true
  restrict_public_buckets = true
}
```

## Security Best Practices (CIS Benchmark Grounding)
1. **Server-Side Encryption**: Always declare `aws_s3_bucket_server_side_encryption_configuration` with `sse_algorithm = "AES256"` or `"aws:kms"`. Unencrypted buckets violate CIS AWS Benchmark 2.1.1.
2. **Public Access Block**: Always attach `aws_s3_bucket_public_access_block` with all four block flags set to `true`.
3. **No Direct ACL in v5**: Do not use deprecated `acl = "private"` in `aws_s3_bucket`. Use `aws_s3_bucket_ownership_controls` or `aws_s3_bucket_public_access_block` instead.
